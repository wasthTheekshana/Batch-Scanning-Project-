# Search and open documents

Status: planned (after index-export)

## Problem
Nobody can find an already scanned document. There is no search screen.

## Behaviour
New **Search** tab: find by free text (barcode/customer id, any index field value), field
filters, project, status, date range; results table (document, project, key fields, status,
date); open the PDF, show the audit timeline, jump to the Index tab to correct fields.
Respects roles (a viewer can search and open; only editors change fields).
